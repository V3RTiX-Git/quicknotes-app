# QuickNotes

QuickNotes is a simple note-taking web application built with HTML, CSS and JavaScript. It allows users to create notes, organise them into Personal, Work and Study categories, search through their notes, delete notes and keep them saved in the browser using localStorage.

## Features

- Add new notes
- Categorise notes as Personal, Work or Study
- Display the date and time each note was created
- Delete notes
- Search notes by their text
- Validate note length
- Display the number of saved notes
- Save notes using localStorage
- Restore notes after refreshing the page
- Responsive layout for smaller screens

## How to run the project locally

1. Clone the repository from GitHub.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. The QuickNotes application will open in your browser.
